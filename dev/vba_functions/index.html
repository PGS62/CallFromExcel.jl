VBA functions

These functions can only be called from VBA, through the object described in Calling from VBA, as for example jl.JuliaCallVBA(...). VBA can also call the worksheet functions, all except JuliaHandleInfo.

NameDescription
JuliaEvalVBAEvaluate a Julia expression from VBA. Differs from JuliaCall in handling of 1-d arrays and strings longer than 32,767 characters. May return data of types that cannot be displayed on a worksheet, such as a dictionary or an array of arrays.
JuliaCallVBACall a named Julia function from VBA. Differs from JuliaCall in handling of 1-d arrays and strings longer than 32,767 characters. May return data of types that cannot be displayed on a worksheet, such as a dictionary, an array of arrays, or arrays of dimension up to 9.
JuliaCallNamedArgsVBACall a named Julia function from VBA, passing positional and named arguments, with ";" marking where the named arguments start. Differs from JuliaCallNamedArgs in the same ways that JuliaCallVBA differs from JuliaCall.
JuliaEvalHandleEvaluate a Julia expression from VBA and return a handle to the result. The VBA counterpart of JuliaEval(JuliaExpression, TRUE).
JuliaHandleReleaseFree the Julia object of a handle created from VBA.
JuliaHandleReleaseAllFree the Julia objects of all handles created from VBA.

JuliaEvalVBA

Evaluate a Julia expression from VBA. Differs from JuliaCall in handling of 1-d arrays and strings longer than 32,767 characters. May return data of types that cannot be displayed on a worksheet, such as a dictionary or an array of arrays.

jl.JuliaEvalVBA(JuliaExpression)
ArgumentDescription
JuliaExpressionAny valid Julia code, as a string. Can also be a one-column range to evaluate multiple Julia statements.

Example. Set d = jl.JuliaEvalVBA("Dict(w => length(w) for w in split(""the quick brown fox""))") returns a Scripting.Dictionary mapping each word to its length, so d("quick") is 5. A dictionary can't be returned to a worksheet.

JuliaCallVBA

Call a named Julia function from VBA. Differs from JuliaCall in handling of 1-d arrays and strings longer than 32,767 characters. May return data of types that cannot be displayed on a worksheet, such as a dictionary, an array of arrays, or arrays of dimension up to 9.

jl.JuliaCallVBA(JuliaFunction, [Arg1], [Arg2], ...)
ArgumentDescription
JuliaFunctionThe name of a Julia function visible from the Julia REPL.
Args...Zero or more arguments. Each may be a number, string, Boolean, empty cell, array or range. A range's values are passed as Excel stores them (its Value2), so cells formatted as dates arrive as serial numbers, not as Julia Dates.

Example. words = jl.JuliaCallVBA("split", "the quick brown fox") returns a one-dimensional VBA array, words(1) to words(4).

JuliaCallNamedArgsVBA

Call a named Julia function from VBA, passing positional and named arguments, with ";" marking where the named arguments start. Differs from JuliaCallNamedArgs in the same ways that JuliaCallVBA differs from JuliaCall.

jl.JuliaCallNamedArgsVBA(JuliaFunction, [Arg1], ..., ";", Name1, Value1, ...)
ArgumentDescription
JuliaFunctionThe name of a Julia function visible from the Julia REPL.
Args...Zero or more positional arguments, then ";", then pairs of name and value, e.g. "a",1,"b",2. Names must be valid Julia identifiers. Each argument may be a number, string, Boolean, empty cell, array or range.

Example. parts = jl.JuliaCallNamedArgsVBA("split", "a,b,,c", ",", ";", "keepempty", False) returns a, b and c, without the empty string between the two commas.

JuliaEvalHandle

Evaluate a Julia expression from VBA and return a handle to the result. The VBA counterpart of JuliaEval(JuliaExpression, TRUE). Raises an error if the evaluation fails. The handle lasts until JuliaHandleRelease or JuliaHandleReleaseAll frees it.

jl.JuliaEvalHandle(JuliaExpression)
ArgumentDescription
JuliaExpressionAny valid Julia code, as a string. Can also be a one-column range to evaluate multiple Julia statements.

Example.

odds = jl.JuliaEvalHandle("Set(1:2:999)")
Debug.Print jl.JuliaCall("in", 7, odds)   ' True
jl.JuliaHandleRelease odds

JuliaHandleRelease

Free the Julia object of a handle created from VBA. Returns TRUE if it freed one, and FALSE otherwise - when the handle was already freed, was created by a worksheet formula (which frees its own), or isn't a handle at all, such as an empty string. So it is always safe to call, for example from a class's Class_Terminate event.

jl.JuliaHandleRelease(Handle)
ArgumentDescription
HandleA handle returned by jl.JuliaCallHandle or jl.JuliaEvalHandle.

JuliaHandleReleaseAll

Free the Julia objects of all handles created from VBA, and return how many. Handles created by worksheet formulas are unaffected.

jl.JuliaHandleReleaseAll()
